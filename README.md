# PROJECT ATHENA — Personal AI Command Center

A responsive, dark-themed front-end prototype for a personal AI command center.

## Features
- Mission Control dashboard with project and task overview
- Demo AI assistant interface (responses are simulated; no live model/API)
- Task manager with priorities, filters, completion, and local browser storage
- Project roadmap for ATHENA, ECHO, ORBIT, MIRAGE, and GENESIS
- AI tools launchpad and permission-first design
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Current prototype scope
This is **Phase 1 — frontend prototype**. It does not currently connect to Firebase, a live AI model, GitHub automation, voice services, or computer-control APIs. Tasks are stored in the browser using localStorage. Demo assistant replies are local scripted responses.

## Safety and deployment
No external actions are performed by this prototype. No Vercel deployment has been created.
